# PIH Frontend

React, TypeScript, Vite, Tailwind CSS, TanStack Query/Table, Axios, React Router, and Lucide UI.

```powershell
Copy-Item .env.example .env
npm install
npm run dev
```

The app runs at http://localhost:5173 and expects the API at http://localhost:8000/api. Use `npm run build` for a production build.
